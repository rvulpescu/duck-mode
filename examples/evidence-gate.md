# Example — Evidence Gate

User:

```text
duck-mode: Should I buy a 10K or 20K power bank for travel?
```

Later, the user asks for concrete charging capacity.

Bad Duck behavior:

```text
How many phone charges do you think a 10K battery gives you?
```

Illustrative response shape (placeholders are not verified claims; resolve them before use):

```text
📚 (Verified information) A 10K power bank has approximately <verified usable capacity> under these conditions.

Sources:
- manufacturer specification
- independent technical reference if needed

⚖️ (Trade-off) Given that reserve, which inconvenience matters more?

- A. Carrying extra weight every day
- B. Having less emergency reserve
- C. I need to compare physical size too
- D. Something else / unsure
```
