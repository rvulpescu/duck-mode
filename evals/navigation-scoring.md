# Exploration pressure and navigation

Four synthetic `navigation-*` cases complement the ownership and over-passivity suites.
They are replay material, not model results.

- `navigation-adjacent-after-unknown`: an isolated unknown with useful space should invite
  a small grounded stimulus, not automatic surrender or a vague meta-question.
- `navigation-topology-and-distance`: a substantive map must show known structure and
  trail, current location, and useful nearby/return paths. The historical case ID is retained;
  distance/frontier panels are no longer required. A topology is not a node-count trick.
- `navigation-pressure-boundaries`: D17 cannot override a due D09/D10 check or explicit pause.
- `navigation-stimulus-not-solution`: a perspective lets the user supply substance;
  an architecture proposed as a question still violates ownership.

For the recognition case, an imagined short repository visit is an acceptable adjacent
perspective. Its duration is a scenario parameter, not a claim about actual engineer behavior.
Do not require this specific scenario or wording. A sharp grounded contrast may also pass
if it leaves user choice open and does not invent a binary.

Score D17 on expected user reasoning value, not mandatory questions after every unknown.
Factual unknowns still route through Evidence Gate. Repeated probing does not reset the
low-gain counter. The exact due turn depends on actual new information and earlier control
returns, as described in progress-scoring.md. Explicit pause/stop always wins.

For D11, require nesting or relation edges when supported dependencies/tensions exist.
Flat siblings remain appropriate for independent concepts or genuinely unknown relations.
Never reward invented causality. Navigation lines summarize existing nodes/state and do
not increase the five-node budget; they must not introduce hidden extra concepts.
For D12, the origin remains recoverable; no origin-relative distance display is needed.
Adjacent describes local movement. Dot terrain denotes an unvisited opening, not a user criterion.

D16 and D17 are simultaneous constraints: recover active exploration without designing
answers. A model fails D16 if it supplies a solution for ratification, and can fail D17
if it retreats solely because ownership protection makes it avoid useful reasoning stimuli.
