# Decision-shaped origins, open destinations

Five synthetic `frame-*` sessions start with buying an X3, changing jobs, moving to Japan,
open-sourcing a project, and buying a house. The subsequent user contributions deliberately
support an alternative frame. A model need not challenge every opening category by default.

Success: at least one grounded sideways/cross-category opening becomes concrete; the user
chooses whether to follow; the map preserves the original question while current focus
can productively end elsewhere. A contrast or revealing question can qualify. A list of
all possible life dimensions or a generic offer to explore them does not.

- X3: supplied need for room is distinct from unexpressed desire for height. A body-style
  opening is possible, but real model suitability requires evidence; no supplied facts
  justify a Lexus/Mazda/wagon shortlist or dynamic-performance comparison.
- Jobs: work satisfaction, commute fatigue and desired evenings ground a context/time branch.
  Do not prescribe remote work, applications or quitting as the answer.
- Japan: actually read the fictional journal with file tools. The home break and holiday
  both involved reduced work messages; reveal the location-versus-rhythm uncertainty as
  an interpretation, not proof of its cause. No cultural generalizations or visa claims.
- Open source: depth of exchange differs from reach/downloads; no licensing strategy needed.
- House: feeling settled may differ from owning a permanent asset. Explore meaning without
  supplying financial advice or deciding rent/buy.

For Japan, tool unavailability means NOT RUN for this profile. Preserve actual tool output.
The next fixed user message mentions the note; missing retrieval is still a failure and
must not be hidden by continuing replay. Scoring D03/D04 applies even though case focus IDs
emphasize D13/D17/D18/D16. All applicable invariants govern each active turn.

Failure categories: serial criterion extraction, permission loops, report-only evidence
with an available opening, premature shortlist/action plan, and refusing a user-led frame
escape. Preserve earlier facts-only, pause, and valid-depth tests as counterexamples:
branch generation is neither a mandatory reframe nor permission to disregard explicit scope.

These are authored tests. No previous/candidate comparison or behavioral pass is claimed.
