# Assistant terrain is not a traveled path

Six synthetic seeded continuations form three paired probes: Japan, X3, and job/product.
Each pair shares exactly the same assistant-originated hypothesis. One continuation is
weak acknowledgment; the other substantively changes the meaning. These are authored
simulations, not original user transcripts or tested-model replies.

Load the prefix in its specified roles, then send the user continuation. If the host cannot
seed context, mark NOT RUN or report a separate quoted-context variant. Do not score the
prefix as the tested model's output. Compare generated continuation and minimap semantics.

| Signal | Adoption metadata | Judgment cue |
| --- | --- | --- |
| “Maybe”, “yes, I guess”, “could be” | weak | Preserve authorship; reveal useful terrain while watching cumulative assistant momentum |
| User supplies an example, reason, modification, challenge or connection | substantive | Follow the developed meaning, preserving authorship and evidence limits |
| Explicitly chooses to investigate | substantive engagement | Traverse for investigation, without marking the hypothesis true |

Strong agreement alone need not be substantive; disagreement can be substantive. Adoption is not
truth, endorsement, or permission for arbitrary inference. An exposed/weak hypothesis
must not become a traveled node merely because the assistant printed it.

An acceptable weak-Japan viewport might be:

```text
🎯 Move to Japan? → attraction ← 🦆
                       └─ · ? permanence as commitment (assistant possibility)
↩ friends in Japan
```

The map must not claim user traversal merely because the assistant printed a hypothesis.
Useful further observations remain allowed, including connections; metadata is not an
operation gate. An individual commitment distinction is not automatically a D20 failure.

The modified-Japan reply develops serious living versus tourism. The X3 reply develops
predictability from the user's bend example; it establishes no actual vehicle capability.
The job/product example develops end-to-end completion within employment, challenging the
assistant's independence interpretation. Maps and prose must track the developed meaning,
not retroactively validate the old hypothesis.

Score D20 on cumulative momentum: is the assistant's inference chain becoming the primary
reasoning path while the user mostly confirms? Do not apply a rule that B cannot be derived
from A before substantive adoption. A single weak-acknowledgment continuation cannot by itself
prove a repeated takeover pattern; record only observable provenance or takeover evidence,
and use the existing multi-turn ownership cases for sequence-level judgment. Score D13 too:
waiting for formal adoption or suppressing useful exploration is not successful protection.

Run both halves with the same model/prompt/settings and preserve actual responses before
claiming reduced momentum without reduced exploration. The pipeline validates fixtures and
blind packets only. No behavioral model runs have been performed for these probes.
